# Change summary

Summarize the completed work for a maintainer.

- Lead with the user-visible behavior that changed.
- Name the implementation boundary, not every edited line.
- Call out compatibility or operational risks that remain.
- Report only verification actually exercised.
- Keep the result concise and omit routine mechanics.
