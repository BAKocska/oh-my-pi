## What this probes

This is a conformance probe, not a port; there is no pi origin. It drives the extension-visible half of D5's cancellation ladder and the seven-phase invocation machine: DATA refusal before authorization, cooperative `omp.CancelledError` delivery after authorization, `Context.cancelled()` and `Context.on_cancel()` delivery, delayed interruption after `CANCEL_GRACE`, settlement suppression of escalation, cleanup unwinding, owner-side RunGuard termination and stale-handle refusal, effects-unknown observation, and the three durable abort kinds. `cancel_probe(mode="cooperative")` holds a Python body at an await point; `cancel_probe(mode="guarded_run")` holds an Environment-owned command open so an external harness can drop the invocation guard.

The re-runnable `smoke()` uses inert DATA-owner stubs because ordinary extension bodies do not exist before `EFFECTS_AUTHORIZED` and the examples gate has no live Environment. It feeds framed `CancelDispatch` messages through the current frozen host, drives every extension-reachable row, and asserts owner refusal for every earlier row. The gate's native `Duration` stand-in is opaque, so the host timing exercise temporarily supplies the ruled 0.150-second value while separately checking that the four public exports are the frozen limits exports. The live guarded-run path remains available to P2 or an integration harness; the stub models the same observable public-handle contract without starting a process.

## Closure records

1. **Typed effects-unknown reporting is closed.** The defect was the absence of the documented `Abort` carrier and constructors from the frozen Python surface. `crates/py/python/omp/params.py:179-225` now defines the five typed constructors, and `crates/py/python/omp/__init__.py:716-717,1641-1642` exports `Abort`. The current smoke constructed `Abort.effects_unknown(...)`, observed its `effects_unknown` kind, and constructed `Aborted` from typed `Abort.interrupted(...)` and `Abort.skipped(...)` values.

2. **Scope cancellation state and callbacks are closed.** The defect was that `CancelDispatch` cancelled the task without setting `Scope.cancelled` or firing registered callbacks. `crates/py/python/omp/_scope.py:72-97` now records the first request and drains callbacks, while `crates/py/python/omp/_host.py:156-166` schedules both operations from the dispatch path. A framed current-host dispatch was re-observed to make `Context.cancelled()` true and fire its `on_cancel` callback exactly once.

3. **The staged cancellation ladder is closed.** The defect was that task cancellation and `_interrupt` ran back-to-back, eliminating the cleanup grace. `crates/py/python/omp/_host.py:137-170` now performs immediate task cancellation and starts the grace timer; `crates/py/python/omp/_host.py:214-270` interrupts only a still-live dispatch and cancels pending escalation on settlement. The smoke re-observed no interruption before the ruled 150 ms, one interruption after the grace for an intentionally unsettled task, and no later interruption for a task that settled cooperatively.

4. **Cancellation-adjacent frozen payloads and limits conform.** `EffectsNotAuthorized` was formerly raised by this probe with a prose-only argument; `crates/py/python/omp/_errors.py:89-98` carries the ruled `(invocation, spec)` payload, and `cancel_probe.py:176` now supplies and verifies it. `crates/py/python/omp/limits.py:24,42-49` defines `MAX_FRAME_BYTES=67_108_864`, `CANCEL_GRACE=150ms`, `SHUTDOWN_GRACE=2s`, and `HEALTH_TIMEOUT=5s`; `crates/py/python/omp/__init__.py:699-710,1327-1507` exports them, and the smoke re-observed their public binding (plus the exact integer frame limit). `PolicyDenied` remains the required frozen `OmpError` dataclass at `crates/py/python/omp/policy.py:672-681`; the existing positional construction at `cancel_probe.py:410` was re-observed with required `code="probe"` and `OmpError` identity.

No findings remain open.
